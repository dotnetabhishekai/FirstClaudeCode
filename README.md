# FirstClaudeCode

A collection of standalone, single-file HTML web tools — each one is self-contained (HTML + CSS + JS) and runs by simply opening the file in a browser. No build step, no install.

## Tools

- **[bookmark-manager.html](bookmark-manager.html)** — Card-based bookmark manager with categories, tags, search, and read/unread status. Saves to `localStorage`.
- **[invoice-generator.html](invoice-generator.html)** — Live-preview invoice generator with line items, tax calculation, and print/Save-as-PDF support.
- **[snake.html](snake.html)** — Snake game with smooth movement, particle effects, speed levels, pause, high score, and keyboard/touch controls.
- **[csv-visualizer.html](csv-visualizer.html)** — Drag-and-drop CSV dashboard with type detection, per-column stats, and Chart.js bar/line/pie charts. Try it with [sample-data.csv](sample-data.csv).

## Usage

Open any `.html` file directly in your browser — that's it.

## Other files

- `prompts_library.txt.txt` / `doc.md` — original prompts and feature summaries used to generate each tool, useful as a reference when extending them.
- `CLAUDE.md` — guidance for Claude Code when working in this repo.
